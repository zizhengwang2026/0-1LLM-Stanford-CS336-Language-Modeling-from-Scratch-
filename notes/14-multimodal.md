# 第14讲 · 多模态模型（综合 × DIY-LLM 第15章）

> **本讲位置**：CS336 课程的"视野拓展"。前面 13 讲都在讲**纯文本** LLM，这一讲把眼睛（图像）、耳朵（音频）装上去，看"从零造 LLM"之后怎么走向通用模型。
>
> **一句话定位**：多模态的本质就一句话——**把所有模态都翻译成 token，交给 Transformer 统一处理**。难点在于"怎么翻译"和"怎么对齐"。

---

## 一、什么是多模态 / Token 概念的扩展

"Token"不再只是文字：

| 模态 | 怎么变 token |
|------|-------------|
| 文本 | BPE 分词（见第1讲） |
| 图像 | 切成 patch → ViT 编码；或 VQ-VAE 离散编码 |
| 音频 | 频谱帧 |
| 视频 | 时空 patch |

Omni Model（全能模型）的目标：任意模态组合输入/输出。GPT、Gemini 宣称"原生多模态"，但开源方案多用外部视觉模型中转。

---

## 二、CLIP：用对比学习对齐图文

CLIP 是多模态的基石，思路很巧：

- **数据**：互联网现成的 4 亿对"图+文字描述"（弱监督，不用人工标注）。
- **目标（对比损失）**：让"正确配对"的图文向量相似度高、错误配对低（n 路分类的双向交叉熵）。
- **视觉编码器**：**ViT（Vision Transformer）**——把图切成 14×14 的 patch 当"视觉 token"，过 Transformer 再聚合。
- **意义**：zero-shot 直接超过 ResNet；证明"对比对齐"比"直接生成描述"高效得多。
- **局限**：偏高层语义、细粒度弱；依赖超大 batch；OCR 差。

> SigLIP 的改进：把 Softmax 改成 **Sigmoid 倾向的逐对二分类**，损失和 batch 大小解耦——小 batch 也能训好，效率更高。

---

## 三、VLM 架构：把图像"注入"语言模型

主流范式就三步（**Encoder + Adapter + LM**）：

1. **Vision Encoder**（冻结的 CLIP/SigLIP）：把图变成一串视觉向量。
2. **Projector / Adapter**（可训练）：把视觉向量"翻译"成伪文本 token，对齐到 LLM 的词空间。可以是线性层、MLP、或 cross-attention（类似 Q-Former 思想）。
3. **LM**（冻结或微调）：把视觉 token 当普通 token 自回归生成文字。

**代表模型**：

| 模型 | 特点 |
|------|------|
| **LLaVA** | CLIP ViT + 单层线性投影 + Vicuna；用 GPT-4 合成 158K 对话做训练；两阶段（先对齐冻 LM，再指令微调冻视觉） |
| **LLaVA OneVision** | 换 SigLIP + 2 层 MLP + Qwen-2 72B；AnyRes 高分辨率（全局+最多 9 个 crop），支持单图/多图/视频 |
| **Qwen-VL 系列** | cross-attention 适配器压到 256 token；Qwen2-VL 用动态分辨率 + M-RoPE（多维旋转位置编码，支持视频）；Qwen3-VL 加 DeepStack 跨层注入 |

> 关键洞察：单图训练的能力能**自发迁移**到多图、GUI、视频追踪——这是基础模型特征的通用性。

## 四、离散化路线：Chameleon

另一条路：**全 Token 化**。图像和文本都用离散 token，统一一个 Transformer。

- 用 **VQ-VAE** 把图（512×512）压成 1024 个离散 code（8192 大小的码本），重训 BPE 把图和文字放进同一词表。
- 优势：架构最统一；劣势：**训练不稳定**（文本低熵/图像高熵导致 norm 膨胀、loss 发散，需 QK Norm + Z-loss），且离散会丢信息。

> 当前格局：**连续编码器 + Transformer + Diffusion 生成**胜出（图像/视频输出用扩散模型比离散生成好）。

---

## 五、多模态与"从零训练 LLM"的关系

- 多模态模型**大多复用现成的预训练 LLM 和 Vision Encoder**，只训中间的 Adapter——成本远低于从零训练多模态。
- 这正好呼应本课程的定位：你把文本 LLM 榨透（架构/训练/对齐），加一个视觉编码器 + 投影层，就是一个 VLM 的雏形。
- 真正的"原生多模态"（从零一起训图文）成本极高，是 Google/OpenAI 的战场。

## 七、常见坑 & 面试可能问

1. **"多模态模型为什么大多冻结视觉编码器？"** → 视觉编码器（CLIP）已训好且贵，只训 Adapter 性价比最高。
2. **"CLIP 为什么用对比学习而不是生成 caption？"** → 对比学习用现成图文对、效率更高、泛化更好。
3. **"ViT 怎么把图变成 token？"** → 切成 patch，每个 patch 当成一个 token 过 Transformer。
4. **"连续表示 vs 离散 token 路线哪个好？"** → 当前连续编码器+扩散生成胜出，离散易丢信息且训练不稳。
