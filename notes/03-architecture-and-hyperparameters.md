# 第 3 篇笔记：语言模型架构与超参数

> 来源合并：Stanford CS336 第 3 讲（Architectures, Hyperparameters）+ Datawhale《DIY-LLM》第 4 章（语言模型架构和训练的技术细节）
> 这一讲回答一个很实际的问题：**从零写 LLM，架构每个零件长啥样、为什么这么设计、那些超参数（维度/头数/宽深比）到底怎么定。** 这是 A1（手写 Transformer）的直接理论基础。

## 一、为什么这讲重要

CS336 让你从 PyTorch 原语手写一个 Transformer，不准用现成封装。那你第一步就得自己决定：用哪种归一化、位置编码怎么加、激活函数选哪个、隐层多大、头数多少……这些不是拍脑袋的，业界沉淀了大量"经验法则"。这讲就是把它们讲清楚——**既懂"长什么样"，又懂"为什么"**。

## 二、先回顾标准 Transformer（2017 原始论文）

Transformer 的核心创新是**自注意力机制**，抛弃了 RNN/CNN，让序列能并行计算、还能捕捉长距离依赖。

### 2.1 自注意力（Scaled Dot-Product Attention）
- 输入 `X` 通过三组权重映射成 Query（Q）、Key（K）、Value（V）。
- 注意力 = `softmax(QKᵀ / √d_k) V`。
- **为什么要除 √d_k？** 点积 `Q·K` 的方差会随维度 `d_k` 线性放大，不除的话数值太大，会把 softmax 推进梯度极小的饱和区。除一下把方差拉回稳定范围，训练才不崩。
- **为什么要多头（Multi-Head）？** 单头只能看一种"查询-键-值"关系；多头让不同头在不同子空间并行关注不同模式（比如有的看语法、有的看语义、有的看长程依赖），最后拼起来。而且每个头在低维算，总计算量和单头差不多，但表达能力高得多（相当于高秩分解）。

### 2.2 位置编码：Transformer 本身是"排列不变"的
自注意力对输入顺序无感知——"我爱你"和"你爱我"在它眼里是同一个集合。所以必须显式加位置信息。
- **正余弦绝对位置编码**（原始论文）：用 `sin/cos` 按位置生成固定向量，和词向量相加。无参数、计算高效，但它只建模**绝对位置**，长序列性能会衰减、难以表达"相对距离"。

### 2.3 LayerNorm + 残差（原始是 Post-Norm）
- **残差连接**：`Output = Input + Sublayer(Input)`。让信息能绕过某些层直达，反向传播时梯度有"高速公路"，至少保留恒等映射能力，深层才训得动。
- **LayerNorm**：把激活值标准化（减均值除标准差，再乘可学习的 γ、加 β），稳定分布、加速收敛。
- 原始论文顺序：**子层 → 残差 → LayerNorm**（这就是 Post-Norm）。

### 2.4 FFN + ReLU
每个 Transformer Block 里注意力之后是个前馈网络：`FFN(x) = max(0, xW₁+b₁)W₂+b₂`，中间维度 `d_ff` 通常是 `d_model` 的 4 倍。原始用 ReLU 激活。

## 三、现代变体：现在主流模型怎么改的

架构每年都在微调，但有几条清晰的演化主线：

### 3.1 归一化：Pre-Norm + RMSNorm
- **Pre-Norm 替代 Post-Norm**：改成"**LayerNorm → 子层 → 残差**"。好处巨大——训练更稳、不需要复杂的学习率 warmup、能训 100+ 层深网络。现在是 GPT-3、PaLM 等的默认。核心思想是"**保持残差流干净**"：输入从底层直达顶层，梯度无损穿过。
- **RMSNorm 替代 LayerNorm**：LayerNorm 要算均值和标准差，而 RMSNorm 只保留"除以均方根"（去掉减均值的步骤）。表达能力几乎无损，但少了一次内存搬运、少了要加载的 β 参数，速度明显更快。LLaMA、PaLM、Chinchilla、T5 全用 RMSNorm。
- **双归一化（Double Norm）**：Grok、Gemma 2 在子层前后都放归一化，"哪里不稳撒哪里"，深层训练更稳。

### 3.2 去掉 bias（偏置项）
现代实现几乎把所有线性层的 bias 去掉。原因和 RMSNorm 类似：bias 算术强度低、内存搬运贵，而且实证上**去掉 bias 训练反而更稳**。所以这已从"省显存优化"升级成"默认稳定性保障"。

### 3.3 激活函数：ReLU → GeLU → SwiGLU
- ReLU 简单但在原点不可微；GeLU 更平滑（GPT 系列用过）。
- **门控线性单元（GLU）**是 2023 年后绝对主流。它把 MLP 隐藏层分成"内容通道"和"门控通道"两路，门控用 sigmoid/swish 生成 0~1 的开关，逐元素相乘——像一扇**智能百叶窗**，根据输入动态调节每个神经元通过多少。
- **SwiGLU**（用 Swish 做门控）是当今大多数模型（LLaMA、PaLM、OLMo）的选择，性能略优于 GeGLU，代价是计算稍贵。

### 3.4 位置编码：RoPE 一统江湖
**RoPE（旋转位置编码，2021 苏剑林 RoFormer）**现在几乎是先进模型的标配。核心思想：
- 给每个位置的 query/key 乘一个"旋转矩阵"（把向量按位置角度转一下）。
- 当计算注意力 `Q·Kᵀ` 时，旋转矩阵的数学性质会让结果里自然冒出 `R(m-n)`——也就是两个 token 的**相对位置**信息，而不是绝对位置。
- 优点：**显式相对位置、可无限外推、零额外参数**。为什么大家都爱用？因为它契合注意力的本质（注意力关心的是"关系"而非"绝对坐标"）。

### 3.5 注意力机制变体（主要为了省显存、提推理效率）
- **KV Cache**：自回归生成时，把历史算过的 K、V 缓存起来，新 token 不用重复算。这是推理加速的基础。
- **MQA（多查询注意力）**：所有头共享同一份 K、V，省显存，但表达力下降。
- **GQA（分组查询注意力）**：折中——把 Query 分组，每组共享一份 K、V。Qwen、LLaMA 都用它。从"算术强度"角度看：自回归推理每步都要从 KV Cache 读全部历史，算术强度很低（GPU 在等数据），GQA 用更多 Query 头"摊薄"内存访问代价，吞吐量大幅提升，不只是省显存。
- **MLA（DeepSeek 多头潜在注意力）**：用低秩联合压缩把 K、V 压到极小潜在空间，KV Cache 能减 90%+，DeepSeek 系列专用。
- **稀疏 / 滑动窗口注意力**：不是看全部历史，而是只看局部窗口 + 偶尔全局，控制长文本成本。2024-2025 流行"全局+局部交替"混合范式（Cohere、LLaMA 4、Gemma、OLMo 都用）。

## 四、超参数怎么定（经验法则）

突然让你从零训个模型，超参一堆，但其实只有少数几个真正需要调，而且都有共识：

- **FFN 中间维度 `d_ff`**：用 ReLU 的模型设 `4 × d_model`；用 GLU 类激活的设约 `2.66 × d_model`（即 8/3 倍）。实验表明 1~10 倍区间都接近最优，不用死守。
- **头数与维度**：`NumHeads × HeadDim ≈ d_model`（比例≈1），GPT-3、T5、PaLM、LLaMA 2 都遵循（T5 是例外，用了 16 倍）。
- **宽深比（width/depth）**：约 **100** 时损失最小。但还受系统工程约束——**越深 → 流水线并行**（有"气泡"、调度复杂，工程师不爱）；**越宽 → 张量并行**（切大矩阵分片，通信规整、好实现）。所以实际模型大多适度控深、保一定宽度，是"表达能力 / 计算效率 / 工程复杂度"的最佳妥协。
- **词表大小**：早期 3万~5万，现在多语言生产模型普遍 **10万~20万**（如 GPT-4、Cohere Command）。大词表对低资源语言特别有用——能用更少 token 表示，降低推理成本。
- **Dropout 与权重衰减**：预训练基本**不用 dropout**（数据太大、单轮训练几乎不过拟合）。**权重衰减仍普遍用**，但有趣的是——它真实作用不是"防过拟合"（单轮根本不过拟合），而是训练末期的**优化加速器**：学习率趋零时，权重衰减和优化动态产生隐性加速，帮模型收敛到更优解。

## 五、训练稳定性技巧

模型越大、训练越久，稳定性越关键。Transformer 里最容易出问题的组件是**两个 softmax**（输出层的、注意力里的）——指数运算和除法容易数值爆炸。

- **z-loss**（PaLM 提出）：在损失里加一项 `λ·log²Z`（Z 是 softmax 归一化因子），把归一化因子压在合理区间，稳定输出层 softmax。Baichuan2、DCLM、OLMo 2 都跟进了。
- **QK 归一化**：在 softmax 之前，先对 Q、K 做 LayerNorm，直接控制数值范围（Gemma 2、DCLM、OLMo 2 用）。层归一化在稳定性上的有效性"惊人"。
- **软截断（Soft-clipping / logit capping）**：内积后、softmax 前，用 `cap·tanh(logits/cap)` 把 logits 软性地夹到 `(-cap, +cap)`（Gemma 2、OLMo 2 用过），但还不算主流。

## 六、这一讲记住这几句话就够了

1. **Transformer 五大件**：自注意力、位置编码、归一化、残差、FFN；核心创新是自注意力。
2. **现代主流改法**：Pre-Norm + RMSNorm（保残差流干净、更快更稳）、去 bias、SwiGLU 激活、RoPE 位置编码。
3. **RoPE 的本质**：旋转 query/key，让注意力点积里自然出现相对位置，无参、可外推。
4. **注意力变体的目的**基本是"省 KV 显存、提推理效率"：KV Cache → MQA → GQA → MLA 一步步压缩。
5. **超参经验法则**：`d_ff ≈ 4×(或GLU下2.66×)d_model`、`头数×头维≈d_model`、宽深比≈100、词表 10万~20万。
6. **稳定训练靠三板斧**：z-loss、QK 归一化、soft-clipping，专门按住两个爱炸的 softmax。
